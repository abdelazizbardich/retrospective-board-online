# Blog Post SEO Checklist for Content Writers

Use this before submitting each article to SprintsPlans. Target: **80+ SEO score** in the blog editor.

---

## Before You Write

- [ ] Check the [sitemap](https://sprintsplans.com/sitemap.xml) — no similar article already exists
- [ ] Pick **one primary keyword** (what someone would Google)
- [ ] List **2–5 secondary keywords** (related phrases, long-tail terms)
- [ ] Choose a **unique angle** — don't repeat an existing post's intent
- [ ] Note **3–8 real SprintsPlans URLs** to link to (only URLs that actually exist)

---

## Article Content

### Length & Depth

- [ ] **1,500–2,500 words** (minimum 800; under 300 is too thin)
- [ ] Directly answers the reader's question / search intent
- [ ] No filler, repetition, or keyword stuffing
- [ ] Actionable, practical information with examples where useful

### Structure

- [ ] **One H1** — the post title (don't add extra H1s in the body)
- [ ] **At least 2–3 H2 headings** breaking the article into sections
- [ ] **H3 subheadings** under H2s where sections are long
- [ ] Heading order is logical (H2 → H3, never H2 → H4)
- [ ] **Short paragraphs** — 2–4 sentences each (aim for ≤80 words avg)
- [ ] **Short sentences** — aim for ≤20 words average
- [ ] At least **one bullet or numbered list**
- [ ] **Introduction** — opening paragraph sets up the topic (30+ words)
- [ ] **Conclusion** — closing paragraph summarizes key takeaways
- [ ] **FAQ section** when relevant (use an H2 like "Frequently Asked Questions")

### Readability

- [ ] Use transition words (however, therefore, for example, additionally…)
- [ ] Prefer **active voice** over passive ("We recommend…" not "It is recommended…")
- [ ] Break up long sentences (none over 25 words if you can avoid it)
- [ ] Use tables or examples where they help

---

## Focus Keyword Placement

Your primary keyword must appear **naturally** in all of these:

- [ ] Post title (H1)
- [ ] SEO title
- [ ] Meta description
- [ ] URL slug
- [ ] First paragraph (introduction)
- [ ] First 10% of the article
- [ ] At least one H2 or H3 heading
- [ ] Body content throughout
- [ ] Conclusion (last paragraph)
- [ ] Cover image alt text (or at least one image alt)

**Keyword stuffing rules:**

- [ ] Keyword appears **no more than ~15 times** in the full article
- [ ] Keyword density stays **under 3%** — use synonyms and related terms instead

---

## SEO Title

- [ ] Written separately from the H1 if needed (can match, but optimized for Google)
- [ ] **50–60 characters** (max 70 — longer gets truncated)
- [ ] Primary keyword **near the beginning** (within first ~30 characters)
- [ ] Includes a **power word** where natural: guide, best, how, top, complete, essential, proven, simple, practical…
- [ ] Includes a **number** where relevant (e.g. "5 Tips", "2026 Guide")
- [ ] **Unique** — not identical to any other post's SEO title

**Example:** `How to Run a Sprint Retrospective: A Complete 2026 Guide`

---

## Meta Description

- [ ] **140–160 characters** (max 170)
- [ ] Includes the primary keyword naturally
- [ ] Summarizes what the reader will learn
- [ ] Ends with a **call to action**: Learn…, Discover…, Find out…, Read…, Get started…
- [ ] At least one complete sentence
- [ ] **Unique** — not copied from another post

**Example:** `Learn how to run effective sprint retrospectives with your remote team. Discover proven formats, facilitation tips, and tools to turn feedback into action.`

---

## URL Slug

- [ ] **Lowercase only**, words separated by hyphens
- [ ] **Under 50 characters**, max **6 words**
- [ ] Includes key terms from the focus keyword
- [ ] No filler words: a, the, and, of, for, with…
- [ ] No repeated words

**Good:** `sprint-retrospective-guide`  
**Bad:** `the-complete-guide-to-sprint-retrospectives`

---

## Excerpt

- [ ] **1–2 sentences** summarizing the article
- [ ] At least 20 characters
- [ ] Can differ from the meta description

---

## Images

- [ ] **Cover image** set for every post
- [ ] Cover image URL format: `https://sprintsplans.com/images/blog/[slug].jpg`
- [ ] **Cover alt text** — describes the image in plain language (5+ characters)
- [ ] All body images have **descriptive alt text**
- [ ] Alt text is natural — don't repeat the keyword unnaturally

---

## Internal Links (Critical)

- [ ] **3–8 contextual links** to other SprintsPlans pages
- [ ] Only link to **real URLs** from the sitemap — never invent URLs
- [ ] Links are **relevant** to the sentence they appear in
- [ ] **Descriptive anchor text** — say what the linked page is about
- [ ] Never use: "click here", "read more", "here", "link"
- [ ] At least **2–4 links** to other **blog posts** (`/blog/...`)

**Good:** `our guide to [retrospective facilitation techniques](/blog/retrospective-facilitation)`  
**Bad:** `[click here](/blog/some-post)` for more info

---

## External Links (Optional but Good)

- [ ] Link to **1–2 authoritative sources** when citing data, research, or external concepts
- [ ] Use descriptive anchor text (not "click here")

---

## Social Sharing Fields

Fill these in, or they'll fall back to SEO title / description / cover:

- [ ] **Open Graph title**
- [ ] **Open Graph description**
- [ ] **Open Graph image** (1200×630 recommended — cover image works)
- [ ] **Twitter title**
- [ ] **Twitter description**

---

## SprintsPlans Brand Mentions

- [ ] Mention SprintsPlans **naturally** where relevant (retrospective tools, online boards, etc.)
- [ ] Only describe **real features**: online retrospectives, real-time collaboration, anonymous voting, actionable insights
- [ ] **Do not invent**: pricing, integrations, awards, statistics, certifications, or features that don't exist

## Schema Type

- [ ] Default: **BlogPosting**

---

## Pre-Submit Final Check

Run through this before handing off:

- [ ] Primary keyword set and placed in all 10 locations above
- [ ] SEO title: 50–60 chars, unique, keyword near start
- [ ] Meta description: 140–160 chars, unique, has CTA
- [ ] Slug: short, lowercase, keyword included, no stop words
- [ ] 1,500+ words with clear H2/H3 structure
- [ ] 3+ internal blog links with good anchor text
- [ ] Cover image + alt text set
- [ ] Excerpt written
- [ ] No duplicate topic or cannibalized keyword vs existing posts
- [ ] All internal links point to real pages
- [ ] No unsupported claims about SprintsPlans
- [ ] Article reads naturally — would you click it in Google?

---

## Quick Do / Don't Summary

| Do | Don't |
|----|-------|
| Write for humans first | Stuff keywords |
| Use real internal links | Invent URLs |
| Keep titles 50–60 chars | Copy meta descriptions across posts |
| Use descriptive link text | Write "click here" |
| Match search intent | Pad word count with filler |
| Mention SprintsPlans naturally | Invent features or stats |
